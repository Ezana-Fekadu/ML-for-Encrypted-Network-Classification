# Contributing Guidelines

Thank you for considering contributing to ML-for-Encrypted-Network-Classification!

## How to Contribute
1. Fork the repository.
2. Create a branch for your feature or bugfix.
3. Write clear, well-documented code.
4. If adding features, include relevant tests and documentation.
5. Submit a pull request describing your changes.

## Coding Standards
- Use clear variable and function names.
- Provide docstrings for all functions and classes.
- Add explanatory comments for complex or non-obvious logic.
- Follow PEP8 style guide for Python code.

## Issues and Bug Reports
- When reporting an issue, please include reproducible steps and error logs.
- If suggesting a feature, describe the use case and possible implementation.

## Code of Conduct
Please be respectful and collaborative; see [GitHub Community Guidelines](https://docs.github.com/en/site-policy).
